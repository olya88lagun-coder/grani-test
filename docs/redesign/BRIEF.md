## Цель

Сайт должен выглядеть дорого и богато: глубокий изумрудный цвет, огранённые камни вместо фото растений, золото тонкими линиями, ритм «тёмный блок, светлый блок». Оценка образа сейчас 7 из 10, ориентир 9.

- `apps/web/src/lib/gem-stone.ts` и тест `gem-stone.test.ts`: геометрия и цвета огранённого камня. Форма берётся из знака типа (`TypeShape`), цвет из семьи типа (1..4). 6 тестов проходят, `pnpm --filter @grani/web typecheck` чистый.
- `apps/web/src/components/GemStone.tsx`: SVG-компонент. Параметр `lit` закрашивает только первые N граней, остальные остаются контуром (индикатор прогресса теста).

## Решение, которое меняет прежнее направление (подтверждено заданием Ольги 2026-10-07)

`docs/design/visual-direction.md` (выбрано 2026-09-17) запрещает: тени, цветные рамки, новые яркие цвета, смешивание палитр на странице. Новый дизайн это нарушает. Предложение: **эволюция, а не замена**.

Сохраняем без изменений: шрифты (Cormorant Garamond 300, Golos Text), радиус 14px, названия переменных, механизм `data-palette`, правила движения и `prefers-reduced-motion`, размеры и отступы, контраст (чернила на панели ≥ 7:1, `--ink-soft` ≥ 4.5:1), 16 типов с семьями и знаками.

Меняем и фиксируем в обновлённом `visual-direction.md` отдельным коммитом в начале:

1. Новый «ночной» набор токенов. Включается атрибутом на секции: `data-band="night"`. Компоненты уже читают `--bg`, `--surface`, `--accent`, `--ink`, поэтому внутри ночного блока они перекрашиваются сами.
2. Разрешены: тонкая золотая линия 1px (`--gold`) на ночных блоках, мягкое свечение только у камней (`filter: drop-shadow`), зерно на карточке для сторис.
3. Запрет теней и цветных рамок остаётся для светлых панелей.
4. Цвет типа задаёт семья камня (бирюза, изумруд, олива, шампань), а не тон панели.

### Токены ночного блока (стартовые значения, проверить контраст скриптом)

| Переменная | Значение | Роль |
|---|---|---|
| `--bg` | `#0A1F17` | фон ночного блока |
| `--surface` | `#10291F` | панель |
| `--surface-2` | `#123226` | плотная панель |
| `--surface-3` | `#163A2C` | самая плотная |
| `--accent` | `#EFE9DA` | заголовки и кнопки (слоновая кость) |
| `--accent-ink` | `#0A1F17` | текст на кнопке |
| `--accent-hover` | `#FBF7EC` | наведение |
| `--ink` | `#EFE9DA` | основной текст |
| `--ink-soft` | `#A3B0A2` | второстепенный текст |
| `--line` | `rgba(205,181,123,.18)` | разделители |
| `--gold` (новая) | `#CDB57B` | линии, числа, подчёркивание |

Для палитры «Глина» (`data-palette="pair"`, совместимость и «Вдвоём») в ночном блоке: `--gold` становится розовым золотом `#E3B3A0`, добавляется `--garnet: #B13A5C` для свечения второго камня. Фон тот же изумрудный. Для «Тумана» ночной вариант выбрать отдельно, в макетах его нет.

Семьи камней (цвета в `gem-stone.ts`): 1 бирюза (`pp**`), 2 изумруд (`pm**`), 3 олива (`mp**`), 4 шампань (`mm**`).
