# Мои грани — локальная интеграция v2

Ветка: codex/personality-atlas-v2. Основа: origin/master 1a2c582. Новых зависимостей нет.

## Что готово

Девять HTML-разделов, графики реальных пяти шкал, 15 базовых и 12 парных редакционных правил v0.3. Три ресурса выбираются по баллам; профиль Софии соответствует утверждённым O85 C90 E25 A35 S65. Интерпретации — гипотезы для самонаблюдения, без медицинских выводов.

Владелец с доступом к полному разбору может редактировать приватные карточку, памятку, план и заметки. API GET/PUT /api/report/[resultId]/atlas проверяет владельца и покупку, защищает запись проверкой Origin, ограничивает структуру и размер запроса. Ревизия обновляется атомарно: устаревшая вкладка получает 409. API не кэширует приватные ответы. Удаление результата/аккаунта удаляет серверный черновик каскадно.

Изменения автоматически сохраняются после паузы 800 мс. Интерфейс различает ожидание, запись, подтверждение, ошибку и конфликт. Несохранённый черновик и неприменённый текст редактора временно сохраняются только в этой вкладке. Это не серверное сохранение. Временная копия восстанавливается после возврата, а при новой серверной ревизии требует явного разрешения конфликта. Старый экземпляр страницы не может очистить более новый буфер. При недоступном хранилище показано предупреждение; память помогает только внутри документа.

Готовый прежний разбор остаётся в раскрывающемся блоке. Друзья, дополнительные главы, цены, действующие покупки и проверки доступа сохранены.

## Запуск и границы

Новая версия включается только при PERSONALITY_ATLAS_V2=1 и готовом полном разборе. По умолчанию выключена: первоначальная страница и состояние подготовки сохранены, новая таблица не читается.

Миграция packages/db/drizzle/0014_personality_atlas.sql подготовлена. Запускалась только в одноразовых тестовых базах и отдельной .dev-db-atlas-v2 на 127.0.0.1:5445. Основная локальная база и production не использовались. Ни merge, ни deploy не выполнялись.

Локальный просмотр: http://127.0.0.1:4340/report/27046172-1e75-4f5d-9679-b24594ea26fc. Условный QA-профиль Софии создан из достижимых ответов теста. На отдельном dev-стенде можно войти через /api/dev/login?name=София%20·%20условный%20QA-профиль. Этот вход уже существовал и разрешён только в development с DEV_LOGIN=1; в production его включать нельзя.

Временные сценарии запуска и снимки находятся вне ветки в outputs/atlas-integration проекта Codex. QA-сессии и локальные базы не включены в Git.

## Проверки

- 41 целевая проверка: модель, SSR, маршрут, API, хранение, конфликты, границы значений, старые ответы и заполненный буфер.
- 76 проверок в совмещённом запуске с прежними покупками, удалением пользователя и платежным сервисом до финальных изменений клиентского буфера; дополнительные проверки буфера запускались отдельно.
- Проверка типов всех шести пакетов прошла; после клиентских изменений повторно проверен web.
- Сборка Next.js прошла: 97 статических страниц.
- 10 браузерных сценариев: desktop/mobile, клавиатура, 320–1920 px, серверное сохранение после reload, два владельца, отсутствие покупки, ожидание готового разбора, Origin, две вкладки, медленная сеть, восстановление после истории, временное хранилище и 2000 символов без пробелов.

Это локальные Chrome-проверки с фиктивными пользователями, покупками и готовым fallback-разбором. Реальные внешние платежи, production OAuth, Safari/iOS и работа production-инфраструктуры в этом этапе не проверялись.
