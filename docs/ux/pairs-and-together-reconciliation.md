# L4: пары и «Вдвоём» — сверка сделанного и оставшиеся пробелы

Дата: 2026-10-07. Автор: Claude. Только сверка: код по этому документу не менялся.

## Две разные «пары»

| | Совместимость по тесту | Пространство «Вдвоём» |
|---|---|---|
| Что это | Разбор сочетания двух результатов теста | Общее пространство вопросов и свиданий на 30 суток за двоих |
| Нужен ли тест | Да, обоим | Нет |
| Приглашение | Ссылка `/p/<токен>`, одноразовая | Ссылка `/together/invite/<токен>`, 7 суток, перевыпускается |
| Согласие партнёра | Партнёр сам соглашается показать результат | Партнёр отправляет запрос, пригласивший подтверждает имя; у обоих отдельное согласие 18+ |
| Оплата | Разбор пары, 399 ₽, платит один, открывается обоим | Доступ 399 ₽ / 30 суток, платит один, открывается обоим |
| Выход | Скрывает страницу и разбор у обоих | Закрывает пространство для обоих |
| Код | `pairs-service`, `pairs.ts` | `together-service`, `together.ts` и соседние |

Названия в интерфейсе различаются («Выйти из пары» и «Выйти из пространства»), цена совпадает случайно (оба 399 ₽), на странице цен это два разных предложения.

## Оставшиеся пробелы

Приоритет: P1 мешает понять, что происходит; P2 неудобство.

| № | Приоритет | Пробел | Почему мешает | Предложение |
|---|---|---|---|---|
| G1 | P1 | **Партнёр не узнаёт, что пространство закрыто.** После выхода другого участника `/together` просто показывает витрину; для закрытых пространств нет сообщения | Человек не понимает, что случилось с его пространством и ответами | В ответ пространства добавить «закрыто: вышел партнёр / удалён аккаунт, дата» один раз; Codex оформляет сообщение, Claude отдаёт данные |
| G2 | P1 | **После окончания доступа экран говорит как новой паре.** Верхняя карточка («Вы теперь вдвоём… доступ откроется, когда дойдёте до основного маршрута») показывается и паре, у которой доступ был и закончился | Вводит в заблуждение: человек платил, а текст как у новичка | Различать «не было доступа» и «доступ закончился» (в данных уже есть `accessUntil`) и показывать отдельный экран с датой окончания и кнопкой продления |
| G3 | P2 | **Пригласивший не видит срок ссылки.** После перезагрузки: «Мы не можем восстановить прежнюю ссылку», без срока и без отметки «истекла» | Непонятно, ждать ли партнёра или выпустить новую | Отдавать `inviteExpiresAt` живой ссылки и показывать «Действует до…» / «Истекла, выпустите новую» |
| G4 | P2 | **Пригласивший не узнаёт о запросе партнёра без обновления страницы.** Уведомлений «Вдвоём» нет (этап 5) | Пара может ждать друг друга часами | Опрос статуса на экране ожидания (как на странице ответа) и позже уведомление в ВК без текста ответов |
| G5 | P2 | **Нет единого объяснения двух продуктов в интерфейсе входа и меню.** «Совместимость» и «Вдвоём» оба про пару | Человек может купить не то | Отдельная строка в блоке цен и на страницах совместимости и «Вдвоём» «чем отличается» (тексты Codex) |
| G6 | P2 | **Нет проверки реальных сторон на живом сайте.** Вход через VK ID, оплата ЮKassa и уведомления в e2e имитируются | Реальные сбои пройдут незамеченными | Ручной прогон двумя людьми на телефонах перед рекламой |

Ни один пробел не нарушает приватность и не открывает чужие ответы. Данные для G1–G3 уже есть в базе или ответе сервера; для G1 нужна небольшая серверная часть (чтение закрытого пространства участника).
