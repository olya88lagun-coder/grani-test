# Поведение в нестандартных ситуациях

2026-10-02. Предложенные правила v1 для технической реализации и проверки перед запуском.
Они уточняют SPEC; коммерческие условия должны совпадать с фактическим экраном оплаты и опубликованной офертой.

## Время, прогресс и награды
- Подписка: 599 ₽ за 30 дней для одного пространства из двух участников — рабочая цена.
- stage = floor(providedPaidSeconds / (30 × 86400)), максимум 12 в годовой программе. Интервалы доступа объединяются, пересечения не считаются дважды.
- milestone 1/2/3 доступен на границах 30/60/90 предоставленных оплаченных дней. Вводные встречи бесплатны и не добавляют paid time.
- cursor отражает фактически просмотренный порядок карточек. Открытый новый этап не заставляет закончить предыдущий.
- Количество карточек не открывает награду раньше. Ранний платёж прибавляет будущий срок доступа, но не уже предоставленное время.
- В v1 нет покупки годовой предоплаты, подарочных тарифов и заморозки оплаченных дней.
- «Пауза занятий» скрывает напоминания и сохраняет место; она не переносит срок оплаты. До подтверждения показывать обе даты: «Занятия на паузе. Доступ оплачен до …».
- «Не продлевать» отключает будущие списания. Доступ остаётся до оплаченной даты; затем новые платные встречи закрыты, заработанные награды доступны по правилам согласия.
- При техническом непредоставлении оплаченного доступа срок компенсируется после проверки. Не считать такой период дважды при компенсации.
- Возвраты обрабатываются отдельным журналом интервалов: отменённый будущий доступ убирается; предоставленное время не переписывается автоматически webhook-ом. Спорные/частичные возвраты передаются поддержке до применения согласованных правил.

## Матрица поведения
| Ситуация | Поведение | Текст/следствие |
|---|---|---|
| Партнёр ещё не присоединился | можно изучить демо; оплату не предлагать до принятия приглашения | «Начнём, когда вы оба будете здесь» |
| Приглашение истекло | старый токен не принимается; инициатор создаёт новый | срок токена 7 дней; повторная выдача отзывает старый |
| Ссылка попала третьему человеку | подтверждение инициатором отображаемого имени принимающего до активации пары | чужой аккаунт не получает ни ответов, ни оплатного доступа |
| Вторая попытка принять ссылку | атомарная проверка места; пространство только на двоих | показать нейтральную ошибку, без раскрытия личности пары |
| Партнёр ответил позже | первый ответ скрыт до второго; после раскрытия оба могут обсудить | никакого показа «кусочка ответа» в уведомлении |
| Один хочет пропустить | карточку можно пропустить; неподелённые ответы не раскрываются | автор может удалить свой черновик; следующий слот доступен обоим |
| Один долго не участвует | никаких штрафов или «партнёр вас игнорирует» | через 7 дней предложить паузу или новое удобное время; не чаще одного нейтрального напоминания в неделю при разрешённых уведомлениях |
| Пропущена неделя | продолжить с сохранённого места или перейти к новой теме | не начислять обязательный долг карточек |
| Пара вернулась после перерыва оплаты | открыть сохранённый cursor; paid time продолжается с прежнего значения | при 45 днях ранее следующий milestone через ещё 15 предоставленных дней |
| Оплата не прошла | не выдавать доступ только по return URL; проверить провайдера | уведомить плательщика о статусе; без повторных списаний в v1, ручной повтор |
| Webhook пришёл дважды/не по порядку | идемпотентность по paymentId и обработка состояния | один успешный платёж = один интервал, late pending не откатывает succeeded |
| Оплатил каждый | второй платёж не создаёт вторую подписку | временно один назначенный плательщик; ошибочный дубль — поддержка/возврат |
| Плательщик отключил продление | статус доступен обоим; платёжные реквизиты только плательщику | без давления на второго участника |
| Хочется сменить плательщика | новая платёжная авторизация после отмены старого продления | никогда не переносить saved payment method между аккаунтами |
| Ответ изменился после раскрытия | автор редактирует свой; партнёру показывается отметка изменения | версия ответа меняется; соответствующий выбор для книги и одобрения устаревают |
| Одобрил только один | книга остаётся черновиком | «Нужно отдельное одобрение второго участника» |
| Нет материалов для книги | milestone остаётся заработанным; экспорт пустого документа не запускается | предложить одну необязательную заметку |
| Фото не загружены | текстовая книга без фотоблока | отсутствие фото не мешает экспорту |
| Пользователь отозвал запись | исключить из новых снимков, отозвать действующие approvals, остановить job | уже скачанные файлы остаются на устройствах |
| Участник выходит из пары | закрыть совместные занятия, отменить будущие списания пространства | сначала экран последствий, затем отдельное подтверждение; оплата/возврат не решаются молча |
| Новый партнёр | новое независимое пространство | не переносить чужие записи, фото, одобрения и книги |
| Удаление аккаунта | отдельная процедура источников, consent и объектов | не обещать удаление всех данных одним UI-флагом; сроки фиксировать только после реализации |
| Нет безопасного совместного общения | можно остановить программу без объяснений | продукт не требует совместного задания ради награды |
| Условия/цена меняются | новая цена не применяется скрыто | порядок уведомления и согласия согласовать до выпуска |

## Выход и сохранённые книги
Выход участника отличается от отмены продления. Перед выходом: «Совместные занятия остановятся. Новые книги не будут создаваться. Уже скачанные файлы останутся у получателей. Будущие списания этого пространства отменятся».
Предложение v1: скачивание ранее одобренного снимка после обычной отмены подписки сохраняется. После выхода участника/отзыва его материалов новые скачивания такого совместного файла закрываются. Личные записи можно выгрузить отдельно, без чужого текста.
Выход не включает автоматический перенос оставшегося оплаченного срока в новую пару. Сначала нужно согласовать политику компенсации с фактической платёжной моделью; это отдельный пункт допуска к оплатному запуску.
Система не должна требовать разрешение партнёра на выход.

## Уведомления
Только при выбранном канале и разрешении. Содержимое: «Ваша встреча готова» или «Можно продолжить, когда вам удобно». Без текста ответов, информации о границах и деталей книги.
Всё, что касается неуспешной оплаты или платёжного метода, направлять плательщику. Не отправлять реальные уведомления из прототипа.

## Проверки перед подключением денег
Два разных аккаунта, приглашение третьему, истечение токена, гонка принятия, hidden payload, stale revision, revoke-during-job, повторный webhook, раннее продление, unpaid gap, timezone boundary, payer exit, удаление файлов. Сейчас это требования: в существующем демо серверной защиты нет.
