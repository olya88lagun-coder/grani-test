# Электронная «Книга о нас» — образец и шаблон
Макет: book/book-sample.html. Данные: book/book-example.json.
Вымышленная пара Анна и Алексей. 16 страниц — размер демонстрационного образца; настоящему пользователю фиксированный объём не обещается.
Это HTML-макет с печатью браузера, а не готовая серверная PDF-генерация. Фотографии в образце не загружаются; показано место для добровольного фото.

## Структура образца
1. Книга о нас
2. Здесь — то, что мы выбрали
3. Как всё началось
4. Первые впечатления
5. Наши способы заботы
6. Анна — об Алексее
7. Алексей — об Анне
8. Прогулка под дождём
9. Чай по воскресеньям
10. Маленькие радости
11. Свидания, которые хочется повторить
12. У каждого — свой ритм
13. Наши маленькие договорённости
14. Ещё один момент для нас
15. В следующей главе
16. Продолжение — в нашей жизни

## Как выбирать страницы автоматически
- Обложка и название доступны всегда, имена/псевдонимы подтверждает пара.
- Сюжетные разделы появляются только при наличии выбранных материалов соответствующей темы.
- Ответы представлены цитатами с автором; совместный рассказ — только из текста, который оба выбрали и одобрили.
- Если нет материала, страницу убрать или предложить короткий вопрос. Не писать вымышленное воспоминание.
- Фото необязательно. Отсутствие фото не оставляет в финальном PDF пустую страницу.
- Длинный выбранный материал разбивается на страницы; текст не обрезать без согласования.
- Один sourceId не повторяется в нескольких текстовых главах по умолчанию. Карточка заботы может быть отдельной сводкой только с явным выбором.
- Базовая версия без AI: шаблоны, выбранные цитаты, короткие пользовательские подписи. Для литературного рассказа доступны ручной ввод пары или будущая отдельная AI-обработка с согласованием.

## Связь первого месяца с книгой
care_preferences → карточка/предпочтения;
everyday_rhythm → личный ритм;
small_gestures → выбранные слова и жесты;
everyday_memories → воспоминания;
words_about_each_other → цитаты друг о друге;
shared_activities → занятия/свидания;
small_agreements → договорённости;
shared_rituals → ритуалы.
Страницы истории знакомства/первых впечатлений в образце показывают возможные материалы второго месяца. Личный ритм/договорённости могут дополняться на третьем. Их полные программы ещё не подготовлены.

## Контракт книги
bookVersion + participant display names + selected source revisions + title/cover + ordered sections + approvals for exact content hash.
source: answer/date_output/manual_addition/care_summary/photo; у каждого authorId/consent/version.
Фотографии: private upload, разрешение включения и удаление/отзыв в общем lifecycle. Конкретное хранилище пока не выбрано.
Результат: приватный PDF, доступ обоим после проверки. Заработанная книга остаётся после отмены подписки; выход/удаление/отзыв согласия обрабатываются отдельно.
Фикстуры с isFictional=true запрещено выдавать за личный материал, отзыв или пользовательскую книгу.

## Дизайн
Тёплая бумага #FFFCFA, сливовые заголовки #4A2230, светлая антиква, широкие поля, тонкие разделители. Короткие цитаты получают пространство, длинные читаются обычным текстом.
Обложка с именами и одним геометрическим знаком. Макет использует резервные системные шрифты; в production подключить брендовые файлы.
HTML print CSS использует A5. Итоговые PDF-верстка, переносы кириллицы, шрифты и разбиение страниц ещё требуют проверки рендером.
Промо-визуал книги должен ясно сообщать электронный формат. Физическая печать/доставка не входят в текущую подписку.

## Данные и AI
Не включать все ответы автоматически. Только выбранные источники; оба согласуют итог. Изменение источника инвалидирует согласование.
Внешнюю AI-обработку не включать по умолчанию; согласие на совместную книгу не равно согласию на передачу внешнему сервису.
