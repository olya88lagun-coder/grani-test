# Грани. Вдвоём — визуальная система

2026-10-02. Пять оформленных экранов и состояния для реализации Claude.
Это визуальный прототип в отдельной ветке, не опубликованная версия grani-test.ru.

## Открыть
После получения ветки feat/together-prototype открыть docs/together/design/index.html в браузере. Файлы шрифтов берутся из существующей папки apps/web/assets/fonts, поэтому сохранять структуру репозитория.
Макет автономный: нет API, авторизации, оплаты, внешних изображений, аналитики и localStorage. Тексты вводить только вымышленные. При перезагрузке данные исчезнут.
Верхняя полоса и нижний переключатель экранов/участников — инструменты review; в рабочий интерфейс не переносить.

## Визуальное решение
Сохраняем палитру пары «Глина» из docs/design/visual-direction.md:
FFFCFA бумага; F6E8E1 и EED8CF панели; 4A2230 сливовые чернила; 2A2224 основной текст; 6E6164 второстепенный.
Заголовки — реальные Cormorant Garamond 300, основной текст — реальные Golos Text 400/600. Системные резервные шрифты остаются на случай недоступности файлов.
Премиальный эффект создают редакционная композиция, тонкие разделители, крупные спокойные заголовки и личная книга. Нет тяжёлых теней, ярких градиентов и оценки отношений баллами.
Две пересекающиеся линии — знак двух историй; не заменяет фирменный гранёный логотип.
Книга изображена как обложка, но рядом всегда указано «Электронная книга PDF». Бумажный подарок не обещается.

## Пять экранов
| Экран | Композиция | Основное действие |
|---|---|---|
| Страница продажи | слева предложение и бесплатная проба; справа обложка с выбранной цитатой; далее встреча, награды 30/60/90, тариф, FAQ | Попробовать 3 встречи |
| Приглашение | личный текст и ссылка; парный знак и ожидание второго человека; отдельный вид принимающего | Скопировать / Присоединиться |
| Пространство пары | сегодняшняя бесплатная встреча главная; рядом история и первая награда; ниже идея вечера и три этапа | Начать встречу |
| Встреча | крупный вопрос, лёгкая подсказка, поле ответа; дальше ожидание и две подписанные цитаты; выбор только своего | Сохранить → обсудить |
| Книга | обложка и выбранные главы; рядом согласование каждого; отдельные пустое/черновик/готово | Одобрить → сохранить PDF |

Новые UI тексты развивают SALES_PAGE_COPY.md; рабочая цена 599 ₽/30 дней за двоих. В прототипе выбран вариант ручного продления, чтобы не обещать ещё не подключённые автоплатежи.
Перед production обе версии цены/условий брать из одного общего config, не поддерживать независимые строки.

## Состояния
Приглашение: инициатор, принимающий, демонстрационное присоединение. Реальные ошибки/истечение токена реализуются по EDGE_CASES.
Встреча: пустая форма, ввод текста, обязательный ответ, ожидание второго, раскрытие, собственный выбор, завершение.
Книга: нет записей, черновик, одобрение одного, одобрение обоих, новая revision после редактуры; PDF-кнопка закрыта до обоих.
Нативные dialog имеют close/Escape/backdrop; на телефоне доступна отдельная кнопка меню.
В реальном приложении hidden answers не попадают в payload клиента. Сейчас всё вымышленное и в памяти страницы, демонстрационные переключатели не являются авторизацией.

## Адаптивность
Desktop ≥1024: container 1248, поля40, две колонки; встреча с боковым пояснением, книга с согласованием справа.
Tablet 768–1023: поля28, уменьшенные промежутки и обложка.
Mobile ≤767: поля22 (18 на320), одна колонка, меню вместо desktop-nav, основные кнопки44–62px; книга и согласование последовательно.
Не использовать horizontal overflow hidden как способ спрятать ошибку. Длинные тексты должны переноситься; проверки 320/390/768/1024/1440 включают ширину документа и реальные элементы.
Focus-visible сливовый, touch targets ≥44px. prefers-reduced-motion отключает движение; контент доступен без анимации.

## Print/PDF
Кнопка открывает стандартную печать браузера только после двух демонстрационных одобрений. Печатный шаблон A5, обложка/цитаты/договорённость/завершение. Нет фиксированного обещания количества страниц.
Это клиентский демонстрационный print, не серверный экспорт. Для production использовать BOOK_MAPPING, авторизованный snapshot, worker/private storage и повторную проверку перед экспортом.
Браузерный QA сохраняет отдельный вымышленный PDF в artifact.

## Передать Claude
Использовать эти HTML/CSS как точный ориентир композиции, токенов, текстов и состояний. Не копировать demo controller в auth/payment слой.
Сохранять существующую шапку/пользовательские компоненты сайта там, где они уже реализованы. Добавить returnTo и самостоятельное together_space по ARCHITECTURE.
Вырезать review-bar/tools, fictional state presets и фиксированные approvals. Данные имён/цен/материалов должны прийти из проверенного серверного состояния.
Кнопки меню/приглашения/книги не вести обратно в обязательный личный тест.

## Проверка
render.mjs запускает Chromium: реальные шрифты, пять ширин, отсутствие переполнения, состояния/навигация, два ответа, выбор, два одобрения, сброс при изменении, диалоги/клавиатура, reduced-motion, вымышленный PDF.
Снимки сохраняются в GitHub Actions artifact; подтверждённые результаты и просмотренные изображения фиксируются в QA.md после выполнения. Не считать этот документ доказательством уже выполненного QA.
