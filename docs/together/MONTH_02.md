# Этап 2. Узнавать друг друга заново

Редакционный черновик для проверки на парах. Узнать новые детали друг о друге и выбрать собственные истории для первой главы.

28 основных встреч, 3 замены и 4 свидания. В среднем 5–10 минут; свидание — около 30 минут. «День» ниже означает слот, а не календарное обязательство. Пропуск разрешён, ответ не становится выбранным для книги автоматически. Индивидуальные записи раскрываются после двух ответов; совместные правила создаются отдельно и требуют двух подтверждений.

## Неделя 01. Истории до и вокруг знакомства

### 1. История нашего знакомства

**Вопрос:** Как вы рассказываете о знакомстве, если оставить только факты и одну запомнившуюся деталь?

Выберите ту часть истории, которой комфортно делиться. Дата может быть примерной.

**Вместе:** Послушайте обе версии и отметьте деталь, которую помните по-разному.

**Источник книги:** m02-d01 → meeting_story; поля: answer, approx_date, setting, remembered_detail. Выбирает автор после раскрытия.

Дополнительное поле «Когда это было (необязательно, можно приблизительно)», до 80 символов, необязательно.

Дополнительное поле «Место или обстановка без точного адреса», до 180 символов, необязательно.

Дополнительное поле «Одна деталь, которую помню», до 400 символов, необязательно.

**Источник книги:** m02-d02 → first_impressions; поля: answer, later_discovery. Выбирает автор после раскрытия.

## Запасные встречи

### Цвет моего интереса

Если выбрать цвет для одного из нынешних интересов, какой это цвет и почему?

Ответ может быть игровой метафорой, без психологической расшифровки.

**Вместе:** Покажите выбранные цвета и поясните свой смысл.

### Короткий маршрут в моём мире

Какие три названия вы бы дали человеку, который хочет узнать о вашем интересе?

Это может быть автор, канал или простое занятие; ссылки необязательны.

**Вместе:** Выберите одно название, о котором интересно расспросить.

### Загадка с пояснением

Какой безопасный факт о вашем увлечении можно сначала предложить партнёру угадать?

Правильный ответ не является проверкой, насколько вас хорошо знают.

**Вместе:** После догадки объясните факт и поблагодарите за любопытство.

## Свидания

### 1. Гид по моему миру

30 минут. В удобном обоим месте; допускается разговор на расстоянии.

1. Каждый выбирает три безопасных предмета, снимка или названия, которые рассказывают о его интересах.
2. По очереди проведите мини-экскурсию: по две минуты на предмет.
3. Слушатель задаёт один вопрос о каждой истории без оценки выбора.
4. Выберите одну деталь для личной записи и решите, хотите ли попробовать связанное занятие.

**Альтернатива:** Если предметы недоступны, используйте три устных описания.

**Запись:** Что сегодня стало для меня новым? Каждый сохраняет собственную заметку; совместное правило — отдельная запись с двумя подтверждениями.

### 2. Плейлист с историями

30 минут. В удобном обоим месте; допускается разговор на расстоянии.

1. Каждый выбирает две композиции и согласует комфортную громкость.
2. Сначала коротко расскажите, с каким периодом или настроением связан выбор.
3. Послушайте по минуте каждой композиции; полные треки необязательны.
4. Назовите общий плейлист и выберите одну собственную историю, которую хочется сохранить.

**Альтернатива:** Можно описать музыку без воспроизведения или взять две другие истории о своих вкусах.

**Запись:** Какая история стоит за моим выбором? Каждый сохраняет собственную заметку; совместное правило — отдельная запись с двумя подтверждениями.

### 3. Поменяться ролями любопытных

30 минут. В удобном обоим месте; допускается разговор на расстоянии.

1. Каждый предлагает доступное занятие из своих интересов, которое можно показать за десять минут.
2. Выберите формат участия: попробовать, наблюдать или только послушать.
3. Проведите два коротких знакомства с занятиями, оставляя право остановиться.
4. Запишите собственное открытие, даже если увлечение не стало общим.

**Альтернатива:** Возьмите рисунок, книгу, коллекцию или устное объяснение без покупки материалов.

**Запись:** Что я узнал о мире партнёра? Каждый сохраняет собственную заметку; совместное правило — отдельная запись с двумя подтверждениями.

### 4. Редакция нашей первой главы

30 минут. В удобном обоим месте; допускается разговор на расстоянии.

1. Откройте только добровольно выбранные и уже раскрытые записи о знакомстве и открытиях.
2. Каждый вслух читает один собственный фрагмент, который считает важным.
3. Проверьте факты: автор исправляет свою запись; разные воспоминания можно оставить рядом.
4. Выберите название и согласуйте черновик либо отложите решение. Одобрение главы не равно одобрению будущей полной книги.

**Альтернатива:** Без экрана прочитайте друг другу собственные заметки и выберите порядок.

**Запись:** Что хочется оставить в нашей первой главе? Каждый сохраняет собственную заметку; совместное правило — отдельная запись с двумя подтверждениями.

## Результат этапа

Наша первая глава. Право на награду появляется после 60 предоставленных оплаченных дней суммарно. Количество выполненных карточек не является платёжным условием: с небольшим количеством материалов получится короткий документ. Подтверждение черновика главы на втором этапе не одобряет автоматически полную книгу на третьем.
