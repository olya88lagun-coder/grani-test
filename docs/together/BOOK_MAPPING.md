# Ответ → страница книги

Дата: 2026-10-02. Контракт для реализации, редакционный черновик.
Обычная книга автоматизирована без LLM: выбранные цитаты и структурированные поля размещаются в заранее подготовленном шаблоне. AI не включён в стоимость и не получает ответы по умолчанию.

## Что именно получает пара
После первого этапа — «Наши способы заботы». После второго — электронный черновик «Наша первая глава» о знакомстве и открытиях. После третьего — персональная электронная «Книга о нас», объединяющая добровольно выбранные материалы трёх этапов.
Это PDF для скачивания. Печать и доставка физической книги в тариф не входят.
16 страниц в book-sample.html — иллюстрация оформления, не обещанное количество страниц.

Запасные карточки имеют собственные bindings. Можно включить выбранную запись замены, но не дублировать её под ID основной карточки.

## Точная единица выбора
Выбор хранится отдельно от ответа: sourceId, sourceRevision, selectedFieldIds, selectedBy[], selectedAt, revokedAt.
Для личной записи selectedBy содержит её автора. Для совместной — обоих действующих участников.
Каждый выбирает собственные поля: например, оставляет remembered_detail, но исключает setting.
Галочка share_in_book в карточке — намерение открыть выбор, а не разрешение автоматически отправлять всю запись в PDF/AI.
Поле answer требуется для отправки карточки, дополнительные поля необязательны. Пустые выбранные поля пропускаются.

## Редактура и два одобрения
1. Сервер проверяет участников пространства, раскрытие ответа, текущую revision, выбор полей и права на источник.
2. Формирует снимок с точными текстами, порядком, выбранными именами, версией шаблона. Не включает скрытые/невыбранные поля, токены, адреса или аналитические данные.
3. Показывает обоим один снимок и его digest. Каждый отдельно подтверждает именно этот digest.
4. Экспорт проверяет два действительных одобрения, право на milestone и актуальность источников заново.
5. Изменение текста, состава, имён, фото, подписи, порядка или шаблона создаёт другой digest. Старые одобрения неприменимы.
6. Отзыв выбора, выход участника или удаление источника блокируют новую генерацию из него. Файл, уже скачанный на устройство, технически нельзя отозвать.

Одобрение главы на втором этапе не переносится на третий. Готовая карточка заботы имеет собственное согласование; включение её в книгу не заменяет одобрения полной книги.

## Недостаток материалов
Нет обязательного числа ответов для получения награды. Пустые разделы не рисуются. Если материалов нет вообще, показываем: «Пока нечего собрать. Выберите хотя бы одну свою запись или добавьте заметку». Право на заработанную награду сохраняется.
Если есть одна выбранная запись — короткий документ с обложкой и этой записью. Не растягивать до 16 страниц.
Предлагаемые необязательные дополнения: «Одна деталь знакомства», «Один момент, который хочу сохранить», «Одна фраза о тебе». Они не заполняются автоматически.
Платёж, число карточек и число страниц книги — три разных показателя.

## Что делает book/book-assembler.mjs
Чистый сборщик текстового снимка: фильтрует разрешённые поля по реальным каталогам, проверяет authors/revision/reveal/selection, упорядочивает разделы, вычисляет SHA-256 и проверяет два одобрения. Ничего не отправляет наружу и не генерирует факты.
Он принимает серверный, уже авторизованный снимок. Не является заменой auth, DB, платёжной проверки, транзакции отзыва согласия, хранения фотографий или PDF-renderer.
V1 поддерживает каталоги M1–M3: личные текстовые записи и отдельно подтверждённые совместные договорённости. Три вводные записи, карточка заботы, фото и обложка с индивидуальным заголовком — описанные расширения, ещё не включённые в сборщик.
Нельзя выдать функцию напрямую клиенту и считать его membership/approval/entitlement доверенными.

## Серверная проверка перед экспортом — обязательная для Claude
Одна транзакционная проверка: active space + те же два участника + актуальные revisions/selections + действительные approvals для digest + earned milestone. PDF job получает неизменяемый снимок, не произвольные sourceIds клиента.
При отзыве во время очереди job отменяется до публикации; готовый объект удаляется/закрывается по политике согласия. Нужны проверки доступа при каждом скачивании.
Кэш ключуется spaceId + digest + templateVersion, не только идентификатором плательщика. Чужие/предыдущие пространства никогда не смешиваются.
Небезопасный текст выводить как текст, не HTML. PDF-шаблон не должен выполнять пользовательскую разметку или загружать произвольные внешние URL.
