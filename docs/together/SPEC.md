# Грани. Вдвоём — продуктовая спецификация v1
Дата: 2026-10-02. Владелец: Ольга. Репозиторий: olya88lagun-coder/grani-test.

## Решения пользователя
- Веб-приложение внутри существующего сайта, публичный вход /together.
- «Вдвоём» — основной продукт привлечения новой аудитории; сайт и VK-сообщество пока новые.
- Тест личности и совместимости добровольный; программа и книга доступны без результатов теста.
- Два аккаунта, одно совместное пространство, одна оплата для обоих.
- Короткие встречи, вопросы, действия, свидания и ежемесячные персональные результаты.
- Автоматическая индивидуальная книга из материалов пары. Никто не оформляет книги вручную.
- Первая крупная книга после трёх оплаченных этапов. Предварительные страницы доступны раньше.
- Годовой путь проектируется сейчас. Подробный контент второй половины года готовится позже.
- Claude Code продолжает техническую разработку. Основная локальная папка пользователя: C:\dev\grani-test.

## Рабочие предположения, требующие утверждения до продаж
Цена 599 ₽ за пару за 30 дней, три бесплатные вводные встречи без карты, один активный двухместный кабинет на участника в первой версии. Это параметры прототипа, а не опубликованные коммерческие условия. Автосписания нельзя считать доступными до проверки шлюза и согласия пользователя. Годовой тариф пока не предлагается.

## Пользовательский путь
Объявление → /together → пример встречи до регистрации → существующая авторизация → создание пространства → короткие предпочтения → приглашение партнёра → принятие после входа → три бесплатные совместные встречи → предложение подписки.
Первый участник может подготовить ответ до принятия приглашения. Раскрытие происходит после ответов обоих участников. После входа нужно возвращать пользователя к исходному приглашению/пространству, сохраняя существующий поток теста.

## Одна встреча
Стабильный ID, тема, версия, время, комфортный вопрос/инструкция, ответы каждого, момент совместного раскрытия, маленькое действие и сохранение своего материала для книги.
Состояния: доступна → черновик ответа → отправлен/ожидание → раскрыта → совместное действие завершено. Пропуск сохраняет прогресс и не требует объяснения. Нет обязательных ежедневных серий, оценки отношений или сравнения с другими парами.
Изменение выбранного ответа обновляет книгу и сбрасывает прежние одобрения.

## Контент и запуск
Для шести месяцев подготовлены редакционные заготовки: 186 коротких встреч и 26 свиданий. Это НЕ 186 готовых проверенных карточек. Финальные вопросы, инструкции, действия и поля результатов должны быть подготовлены отдельно.
Месяцы 7–12 — концепция. Не маркировать их библиотеку как готовую.
Демонстрационные три встречи в prototype.html — только вводный пример, не вся платная программа.
Продление не перезапускает знакомство. Пройденные ID учитываются; любимые ритуалы можно повторять с пометкой «повтор».
Перед платным запуском подготовить и проверить первые шесть месяцев. Для второй половины года утвердить редакционный график; начать подготовку на втором месяце работы продукта и завершить до появления у пользователей соответствующего доступа.

## Автоматическая книга
Участник выбирает свои материалы → пара видит черновик → может убрать/исправить → оба одобряют одну версию → фоновая задача формирует PDF → оба могут скачать.
Дизайн общий, имена/псевдонимы, воспоминания, ответы и выбранные изображения персональные.
Опциональная нейросеть позже может оформить связный рассказ из разрешённых материалов. Начальная версия обязана собирать качественную книгу по шаблону без внешней генерации.
Отмена продления сохраняет право скачать заработанные книги. Выход из пары/отзыв согласия/удаление данных — отдельные события с отдельными правилами; они не равны отмене оплаты.
Скачанный пользователем файл технически нельзя отозвать.

## Визуальное направление
Основа: docs/design/visual-direction.md, палитра pair («Глина»). Фон #FFFCFA, панели #F6E8E1/#EED8CF, акцент #4A2230, текст #2A2224/#6E6164. Cormorant Garamond 300 и Golos Text 400/600, радиус 14px, плоские поверхности без тяжёлых теней. Спокойная композиция, большие интервалы, тонкие знаки, оформление личного альбома.
На главной сайта — заметный вход во «Вдвоём», тесты остаются доступны.
Прототип использует системные резервные шрифты без внешней загрузки; точную типографику переносить из текущего приложения.

## Экраны
/together; создание и приглашение; главная пары («Сегодня для нас», «Что мы собрали», «Следующая глава»); встреча; история и черновик; согласование/скачивание; подписка; настройки/уведомления/выход.
Нужны пустые состояния, загрузка, ошибка, ожидание партнёра, истёкшее приглашение, окончание доступа, возвращение после перерыва.

## Аналитика
Источник первого участника связывается с парой и оплатами. События: вход, создание пространства, принятие приглашения, первая совместная встреча, бесплатное знакомство, подтверждённая оплата, продление, результат этапа, создание/скачивание книги.
Оценивать присоединение второго партнёра, активные пары, стоимость платящей пары и продление. Личные тексты не передавать рекламным платформам.

## Критерии рабочего запуска
Два новых аккаунта проходят путь без тестов; скрытые ответы защищены на сервере; доступ обоим по одной проверенной оплате; повторные платёжные события безопасны; продление не сбрасывает историю; PDF собирается автоматически по одной одобренной версии; чужие данные/файлы недоступны; отмена не блокирует заработанную книгу; старые тесты и покупки работают; мобильный сценарий проверен; публичная /together индексируется, личные страницы нет.


## Дополнение v5 · 2026-10-03 — актуальные игровые форматы
Пользователь утвердил «Угадай меня» и «Свидание из конверта». Подробные сценарии, границы первой версии и приёмка — [ENGAGEMENT.md](./ENGAGEMENT.md).
