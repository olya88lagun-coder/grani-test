## Открыть прототип
После получения ветки откройте docs/together/prototype.html в браузере. Сервер, установка пакетов и доступ к сети не требуются. Шрифты используют системные резервные варианты; точные брендовые шрифты будут подключены в приложении.

## Пройти сценарий
1. Нажать «Попробовать вдвоём».
2. От лица Анны открыть встречу и отправить ответ: ответ Алексея ещё скрыт.
3. Переключиться на Алексея, принять приглашение, открыть ту же встречу и ответить.
4. Увидеть оба ответа и отметить совместное действие.
5. Каждый участник может выбрать собственный ответ для книги.
6. Открыть «Наша история», посмотреть реальные выбранные ответы.
7. Переключить «Этап демо» на третий, одобрить книгу от лица обоих.
8. Использовать печать браузера для сохранения демонстрационного черновика.
9. Изменить выбранный ответ: одобрения сбросятся, повторная печать будет недоступна до нового согласования.

Кнопки участников моделируют двух пользователей в одном окне, не настоящую авторизацию. Данные в памяти страницы исчезают при перезагрузке. Не вводить реальные личные истории.

## Что реализовано в прототипе
Публичная страница, приглашение, главная пары, три вводные встречи, ожидание/раскрытие, отметка действия, выбор материалов, предварительная книга, двухстороннее согласование, сброс одобрений после изменения, концепция двенадцати этапов, печать одобренного демонстрационного черновика.

## Что ещё не реализовано
Next.js routes, независимые аккаунты, реальные токены/DB, серверная защита, оплаты и автопродление, полная библиотека, награды месяцев 1/6/9/12, серверная PDF-генерация, изображения/загрузка фото, уведомления, аналитика, AI.
Логика видимости в демо не является защитой данных: оба ответа находятся в памяти браузера. Рабочая версия обязана защищать их на сервере.

## Проверки
Запуск: node docs/together/verify.mjs
18 проверок: независимость от теста; принятие приглашения; ожидание/раскрытие; валидация; завершение; выбор материалов; milestone; согласование обоими; инвалидирование; безопасный вывод текста; интерактивный путь и печать.
Проверки выполняются также отдельным GitHub Actions workflow. Они не покрывают реальный браузерный layout, сеть, базы или платёжный шлюз.

## Состояние
Это первый этап разработки и материал для review. Прототип не опубликован на grani-test.ru и не является готовым платным сервисом. Локальный запуск/визуальная проверка в сессии Codex были недоступны из-за ошибки запуска среды. Фактические результаты CI смотреть у точного commit/PR.
