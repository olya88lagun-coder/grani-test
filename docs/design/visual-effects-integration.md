# Визуальные эффекты от 14 ноября 2026

## Мини-проба

`HomeTrial` принимает `item: { id, text }`, `remaining` и `continueHref`. Главная передаёт первое утверждение из `SELF_ITEMS` и действующий адрес `/test`. Выбор живёт в состоянии компонента до перехода. Подпись в предпросмотре сообщает размер полного теста.

Для переноса Claude подключает клиентскую обёртку и передаёт `onContinue(answer: { itemId, value }): Promise<void>`. Тип `value` совпадает с `Answer` (целое число от 1 до 5). Обещание должно завершаться после подтверждения переноса. Тогда UI переходит по `continueHref` и показывает подпись про 49 оставшихся утверждений. Во время запроса ввод заблокирован. При отказе UI сохраняет выбранный ответ для повтора и оставляет ссылку в тест.

На стороне интеграции нужно валидировать ID и значение, принять ответ анонимно и решить, как объединять его с существующим черновиком теста. Если по этому ID уже есть ответ, следует сохранить существующий черновик. Повторный запрос должен быть безопасным. Полный тест читает черновик по своей текущей схеме. Значение ответа в адрес страницы не передаётся.

## Тест, результат и пара

- `Questionnaire.crystalKeys` принимает только `id`, `trait` и `reversed` для визуального превью Big Five. Отсутствующие ответы для цвета считаются нейтральными. Цвет может меняться по мере ответов. Тизер за 5–3 ответа использует силуэт и размытую надпись «Твой тип». Имя появляется после расчёта результата.
- `ResultReveal` получает готовые `dir` и `name` личного результата. Диалог открывается при входе на страницу без якоря. Через 2,6 секунды, по кнопке пропуска или Escape фокус переходит к заголовку результата. При уменьшенном движении и при отсутствии `showModal` сразу видна основная страница.
- На страницах пары `PairGemStone` и `PairGemThread` оборачивают существующие портреты и визуально связывают их. В приглашении камни декоративные, на карте пары они соответствуют уже полученным типам.
- На телефоне герой слегка сдвигается при прокрутке и не запрашивает доступ к датчикам. Если браузер не поддерживает `IntersectionObserver`, герой остаётся статичным.

## Аналитика и счётчик

Для Claude. Подключить события по текущему контракту `/api/funnel`. Точки показа и взаимодействия: герой вошёл в экран, первый сдвиг камня, пять подписей раскрылись, мини-проба показана, первый выбор, перенос подтверждён, заполнены 25/50/75% кристалла, показан тизер, началось раскрытие результата, раскрытие пропущено или завершилось, показаны два камня пары. Для границ 25/50/75% можно использовать существующие события прогресса теста. Повторяющиеся движения не отправлять на каждый кадр. В событиях достаточно идентификатора эффекта и действия. Ответ, имя типа, ID результата и токен приглашения в эти события не включать.

Счётчик из пункта 9 можно подключить после появления серверного числа. Для строки пригодны количество за согласованный период и признак достаточности данных. При малом числе или отсутствии данных показ числа скрывается.
