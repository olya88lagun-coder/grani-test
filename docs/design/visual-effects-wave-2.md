# Вторая очередь визуальных эффектов

Реализованы девять приоритетных эффектов из `wow-effects.md`.

- **14. Угадай партнёра.** `PartnerGuess` принимает утверждение `{ id, text }` и существующий адрес приглашения. Ответ подсвечивает второй камень и живёт в состоянии компонента. Claude подключает клиентскую обёртку с `onInvite({ itemId, value }): Promise<void>`. `value` использует стандартную шкалу `Answer` от 1 до 5. При успехе интерфейс открывает `inviteHref`, при ошибке даёт повторить отправку. Нужно согласовать срок жизни анонимного прогноза и связать его с приглашением после входа. Значение ответа не следует передавать в URL или в аналитику.
- **16. Демо «Вдвоём».** Ответ заготовлен для примера. Кнопка переворачивает карточку, затем второе действие открывает пример ответа партнёра. Переходы работают с клавиатуры и касанием. Демо не делает сетевых запросов.
- **18. Ожидание.** `TogetherSpace` использует текущие состояния `invite`, `confirm` и `active`. Смена состояния на `active` запускает соединение только в текущем сеансе. Анимация использует существующий `PairGemThread`. Ни одно из состояний не раскрывает ответы.
- **23. Мои грани.** `MyFacets` принимает публичные для владельца названия черт и рассчитанные баллы. Пять зон на портрете связаны с пятью доступными кнопками. Под камнем остаются исходные шкалы с отметками пограничных значений.
- **24. Друзья.** `FriendsStones` получает число ответивших и разрешённое сервером среднее. Один камень отмечает один ответ. До трёх анкет видны пустые места. Разница оценок показана двумя контурами по пяти шкалам. Индивидуальные оценки друзей остаются за пределами интерфейса.

- **12. Совместимость.** Два одинаковых демонстрационных портрета сходятся к центру при прокрутке к «Как это работает». Параметры вычисляются только в пределах видимой секции. При уменьшенном движении композиция статична.
- **17. Маршрут.** Шесть вех берут содержание из `TOGETHER_SEASON`. Линия и камни проявляются по мере прокрутки. Замок на витрине относится ко второму месяцу. В закрытом маршруте он опирается на номер следующего месяца, если он передан.
- **21. Раскрытие.** Анимация длиной до 1,5 секунды запускается при переходе текущей карточки в `revealed` по серверному ответу. Кнопка «Пропустить» и Escape завершают только анимацию. При повторном открытии уже раскрытой карточки сразу показываются оба ответа.
- **26. Полка пар.** Типы берутся из результатов доступных участнику активных пар. Последняя пара, созданная меньше десяти минут назад, получает короткую вспышку при первом появлении в области просмотра. Признак недавней пары отображается без записи в хранилище.

Для аналитики Claude может подключить `fx_*` по существующему контракту `/api/funnel`: показ и выбор прогноза, успешная передача, переворот и раскрытие демо, состояние ожидания и подтверждение, первый выбор грани, показ камней друзей, сближение в hero, вход на тропу, раскрытие ответов и пропуск анимации, показ полки и переход в карту пары. Достаточно идентификатора эффекта и действия. Ответы, имена, баллы и токены в события не включаются.
