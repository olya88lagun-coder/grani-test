# Грани — визуальное направление

Выбрано 2026-09-17. Основа — пример пользователя (стиль «ботаническая оранжерея на кремовой бумаге»): кремовый фон, плоские тонированные панели без теней, светлая антиква в заголовках, один тёмный «чернильный» цвет на заголовки, ссылки и действия. Пользователю понравились все три палитры, решение — **одна система, три раздела со своей палитрой**.

Превью, по которому выбирали: `scratchpad/build_preview3.py` (не в репозитории); ниже — всё, что из него нужно для кода.

## Палитры по разделам

| Раздел | Палитра | Где |
|---|---|---|
| Тест и личный результат | A «Оранжерея» | первый экран, тест, вход, результат, карточка «мой тип», платный разбор (план 5) |
| Как меня видят другие | B «Туман» | приглашение друзей, анкета друга, сравнение (план 4) |
| Совместимость пары | C «Глина» | приглашение партнёра, страница пары, разбор пары (планы 4–5) |

Палитра включается атрибутом `data-palette` на корневом элементе страницы раздела: без атрибута — «Оранжерея», `data-palette="friends"` — «Туман», `data-palette="pair"` — «Глина». Шрифты, размеры, скругления и компоненты одинаковы во всех разделах.

## Ночные секции — решение от 2026-10-07

Этап 0 редизайна подтверждён прямым заданием Ольги. Это расширение системы: шрифты, размеры, радиус 14px, переменные движения, фокус и клавиатурная работа сохраняются. Набор переключается атрибутом `data-band="night"` на целой секции; отдельные элементы внутри секции не смешивают светлые и ночные токены. Атрибут `data-palette` по-прежнему выбирает раздел.

| Переменная | Ночная «Оранжерея» | Роль |
|---|---|---|
| `--bg` | `#0A1F17` | фон секции |
| `--surface` | `#10291F` | панель |
| `--surface-2` | `#123226` | плотная панель |
| `--surface-3` | `#163A2C` | самая плотная панель |
| `--surface-4` | `#163A2C` | совместимый алиас самой плотной ночной панели |
| `--accent`, `--ink` | `#EFE9DA` | заголовки, основной текст, кнопки |
| `--accent-ink` | `#0A1F17` | текст на кнопке |
| `--accent-hover` | `#FBF7EC` | наведение на кнопку |
| `--ink-soft` | `#A3B0A2` | второстепенный текст |
| `--line` | `rgba(205,181,123,.18)` | декоративные разделители |
| `--gold` | `#CDB57B` | тонкие линии, числа, подчёркивание |
| `--danger` | `#FFB4A8` | читаемые сообщения об ошибке |

В «Глине» ночной фон тот же: `--gold: #E3B3A0` (розовое золото), `--garnet: #B13A5C` (свечение второго камня), `--line: rgba(227,179,160,.18)`. Это работает и на самой секции с `data-palette="pair"`, и внутри такого раздела. Ночной «Туман» ещё не выбран: до отдельного решения не применять ночные секции в разделе друзей.

Разрешённые исключения: золотая линия строго 1px и золотые числа/подчёркивание только на ночном фоне; мягкое `filter: drop-shadow` только у камней внутри ночных секций; зерно только на карточке для сторис. На светлых панелях сохраняется запрет теней, золота и цветных рамок. Само наличие `--gold` в `:root` не разрешает использовать его на светлом фоне. Полупрозрачный `--line` — декор, не единственная граница интерактивного элемента; фокус остаётся цветом `--accent`.

Проверка `node scripts/check-design-contrast.mjs` читает настоящие значения из `globals.css`. Она проверяет основной текст и акцент на всех панелях (≥ 7:1), второстепенный текст на светлом фоне и всех ночных панелях (≥ 4.5:1), текст кнопок (≥ 7:1), золото и ошибки на ночных панелях (≥ 4.5:1). Та же проверка включена в `pnpm test`.

## Тон общих компонентов

Подвал и cookie-баннер читают `--chrome-bg` с запасным значением `--bg`. По умолчанию он равен фону палитры; `data-band="night"` заново связывает его с ночным `--bg`.

Существующие светлые градиенты используют общие `--page-start`, `--page-end`, `--home-page-end`, `--page-panel` и `--page-rule`. Страница и подвал получают один `--chrome-bg`, которым заканчивается градиент. Цвет не следует повторять числами в компонентах или e2e: менять нужно исходный токен страницы. Баннер и внутренняя шапка используют начальный тон градиента; текстовые страницы сохраняют прозрачный подвал над фоном body.

В корневом layout main, подвал и баннер — соседние элементы. Общий тон связан с body через `:has()`; подвал и баннер дополнительно получают палитру через обычные sibling-селекторы. Зависимость общей шапки от `:has()` остаётся: без поддержки этого селектора применяется базовая светлая палитра. Реальный встроенный браузер VK отдельно не проверен.

## Типографика

- Заголовки — Cormorant Garamond **300**, никогда не жирный. Размеры 40 / 56 / 74px (на телефоне `clamp`), межбуквенный интервал −0.01em на 40px и −0.03em на 56–74px, интерлиньяж 1.05–1.2.
- Текст — Golos Text 400: 14px для мелкого текста, 16–18px для основного.
- Метка над заголовком — Golos Text 600, 11px, заглавные, интервал 0.08em, цвет `--accent`. Заглавные буквы — только здесь.
- Вопрос теста — антиква 300, 32–44px.

## Формы и отступы

- Скругление 14px у панелей, карточек, кнопок и вариантов ответа; 999px у меток-«таблеток».
- На светлых панелях теней нет. Ночные исключения описаны выше. Глубина — только сменой тона панели: `--bg` → `--surface` → `--surface-2` → `--surface-3` → `--surface-4`. Цветных рамок у панелей нет.
- Внутренние отступы панелей 28–42px (на телефоне не меньше 21px), расстояние между секциями 64–96px, между элементами 14–21px.
- Кнопка: фон `--accent`, текст `--accent-ink`, 14px 21px, стрелка «→» в конце. Большая кнопка первого экрана — 21px 28px. Второстепенная — прозрачная с внутренней линией 1px цвета `--accent`.
- Вариант ответа — панель цвета `--bg` на `--surface`; выбранный закрашивается `--accent`, текст `--accent-ink`, круглая отметка.
- Шкала — дорожка 6–8px цвета `--surface`, заливка `--accent`, балл антиквой 34px, уровень меткой («Высокая», «Низкая», «На границе»).

## Типы: семья и знак

Тон светлой панели по-прежнему задаётся семьёй. Цвет огранённого камня задаётся отдельно семьёй из `gem-stone.ts`: 1 — бирюза (`pp**`), 2 — изумруд (`pm**`), 3 — олива (`mp**`), 4 — шампань (`mm**`). Это не меняет тон панели и палитру текста. Контурный знак сохраняется там, где нужен монохромный вариант. Исходная система: **тон панели по семье** (первые две буквы каталога: открытость и добросовестность) плюс **гранёный знак**: контур фигуры, внутренний контур на 45% размера и линии граней от центра к вершинам с прозрачностью 45%, линия `--accent`.

| Семья | Каталоги | Тон панели |
|---|---|---|
| 1 | `pp**` | `--surface` |
| 2 | `pm**` | `--surface-2` |
| 3 | `mp**` | `--surface-3` |
| 4 | `mm**` | `--surface-4` |

| Каталог | Тип | Знак |
|---|---|---|
| `pppp` | Вдохновитель | star |
| `pppm` | Реформатор | triangle |
| `ppmp` | Созидатель | hexagon |
| `ppmm` | Архитектор | square |
| `pmpp` | Искра | star |
| `pmpm` | Бунтарь | triangle |
| `pmmp` | Мечтатель | drop |
| `pmmm` | Изобретатель | diamond |

Знаки внутри одной семьи не повторяются, поэтому пара «тон + знак» у каждого типа своя. Логотип — знак hexagon рядом со словом «Грани» антиквой.

Шрифты для картинки — файлы `.woff` из пакетов `@fontsource/cormorant-garamond` (300) и `@fontsource/golos-text` (400, 600), кириллица и латиница.

## Чего не делать

- Не добавлять тени, золото и цветные рамки светлым панелям. На ночных секциях действуют только перечисленные выше исключения.
- Не делать заголовки жирными и не смешивать две антиквы.
- Не вводить яркие цвета вне утверждённых семей камней и ночных токенов; светлая система сохраняет тон панели и знак.
- Не использовать тона панелей для текста — они не проходят по контрасту.
- Не смешивать палитры разделов на одной странице, кроме ссылки-перехода в другой раздел. Светлый и ночной наборы могут чередоваться целыми секциями; внутри одного компонента набор единый.

## Движение

- Общие переменные в `:root`: `--ease-out` (кривая `cubic-bezier(0.2, 0.8, 0.2, 1)`), `--dur-fast` 160 мс, `--dur-base` 200 мс, `--dur-slow` 450 мс. Новые переходы берут их, а не `ease` и случайные миллисекунды.
- Анимируем только `transform` и `opacity`. Полоса прогресса теста и шкалы результата — `scaleX`, а не `width`.
- Частые действия быстрые: выбор ответа и смена экрана теста до 200 мс. Редкие моменты длиннее: шкалы результата заполняются 700 мс по очереди.
- Кристалл на главной мягко парит (9 с, ±6 px), подписи черт проявляются по очереди один раз.
- Нажатие: у кнопок и вариантов ответа `scale(0.97–0.98)` при `:active` — на телефоне нет hover.
- При `prefers-reduced-motion` все анимации выключены, остаётся только смена цвета, рамок и прозрачности.
