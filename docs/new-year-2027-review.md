# «Мои грани — 2027»: локальный MVP

Дата: 27 октября 2026. Ветка: `feat/new-year-2027`, база `origin/master` — `a349627`.

Актуальное локальное превью с зимним фоном: http://localhost:4458/new-year-2027

## Что сделано

- Отдельная страница внутри существующего сайта, с общей шапкой и подвалом. Ночной изумрудный, кремовая карта, мягкое золото, существующий фирменный кристалл. Отдельный зимний фон добавляет фактуру минерала, хвою с инеем и тёплый свет по краям. Новые библиотеки не добавлялись.
- Шесть вопросов: год, благодарность себе, что оставить позади, направление, цель, препятствие. У каждого есть варианты, свободный ответ до 300 символов, пропуск и возврат.
- Карта: выбранное направление, отражение всех заполненных ответов, опоры, цель, редактируемый первый шаг и план «если — то». Полностью пропущенный сценарий явно помечен общим черновиком.
- У вошедшего пользователя читаются только его последние пять шкал Big Five. Проверяются диапазон 0–100 и конечность чисел. Границы 45–55 взяты из существующей `traitLevel`. Формулировки — варианты действий, без предсказаний и диагнозов.
- Гость проходит сценарий без входа. Отсутствующий, повреждённый или недоступный профиль не подменяется примером. Профиль можно отключить или проверить повторно.
- Черновик ответов, правки шага и плана, выбор использования профиля сохраняются только в `sessionStorage` текущей вкладки. Отдельная кнопка удаляет черновик. При запрете хранилища сценарий продолжает работать с явным предупреждением.
- При изменении цели/направления первый шаг пересобирается; при изменении препятствия пересобирается запасной план. Исправление других ответов сохраняет правки карты.
- PNG создаётся локально через Canvas. По умолчанию экспорт содержит только безопасный заголовок, нейтральную подпись, кристалл и адрес спецпроекта. Имени, шкал, ответов и личной цели в нём нет.
- Цель и первый шаг добавляются только по явному выбору, с предпросмотром всего экспортируемого текста. Длинный текст увеличивает высоту файла, а не обрезается. Native share имеет скачивание как запасной вариант; отмена отправки не считается ошибкой.
- Аналитика использует существующие согласие, готовность SDK, проверку боевого домена и исключение устройства владельца. Новые события фиксированы: `new_year_start`, `new_year_complete`, `new_year_download`, `new_year_share`. Ответы, шкалы, цели и идентификаторы не передаются. Цели в кабинете Метрики не создавались.

## Что изучено и сохранено

Проверены Next.js 16.3.5, React 19.3, pnpm, CSS-токены, Cormorant Garamond / Golos Text; серверная сессия, `currentUser`, `getLatestResultId`, `getResultForOwner`, текущая аналитика и cookie-выбор.

Существующие страницы, авторизация VK ID, покупки, цены, доступы, платные отчёты, юридические тексты, схема и миграции БД не изменялись. Изменения состоят из новых файлов. Новый API отдаёт `Cache-Control: private, no-store, max-age=0` и `Vary: Cookie`; пользователь не выбирается параметром запроса.

Маршрут пока `noindex, nofollow`, без ссылок из главной страницы и без добавления в sitemap. Письмо себе и парный режим не включены. Версия черновика и стабильные ID вопросов оставляют возможность расширения без новых активных режимов.

## Ограничения первой версии

- Карта собирается по прозрачным правилам. Она не использует внешнюю генеративную модель и не выдаёт советы за результат психологической диагностики.
- Вход остаётся существующим: после VK ID нужно вернуться в эту вкладку и обновить профиль. Новый механизм возврата в авторизацию не добавлялся.
- Реальный VK OAuth, production-аккаунты, реальные оплаты и системное окно отправки на физическом iPhone в этой задаче не проверялись. Проверка профиля использовала локальную сессию и синтетический результат в отдельной локальной БД.
- Native share отказ/отмена проверены подстановкой браузерного API. Фактическая отправка другим людям не выполнялась.
- Исходные ответы ассистента из старого диалога вернулись ссылками-заглушками. Тексты реализации написаны по утверждённому описанию пользователя; это не восстановленные дословные оригиналы.
- Приватность означает локальное хранение и отсутствие публикации результата на сервере. Пользователь, включивший личный текст в PNG и отправивший файл, сам раскрывает этот текст получателю.
- Продакшен не публиковался. Ветка не отправлялась в GitHub, PR и merge не создавались.

## Повторный запуск

Использовать Node >=24 и зависимости из lock-файла. Для тестов в этой Windows-среде задать `TEMP` и `TMP` в доступный локальный каталог. Для браузера локальный сервер и Chrome должны работать в одной среде; ограниченный запуск Chrome блокировал localhost.

```powershell
pnpm exec vitest run --maxWorkers=4 --testTimeout=120000 --hookTimeout=120000
pnpm typecheck
$env:E2E_BASE_URL='http://localhost:4458'
pnpm exec playwright test -c e2e/playwright.config.ts new-year-2027.spec.ts --workers=1
pnpm --filter @grani/web build
```

Локальные APP_URL / DATABASE_URL / SESSION_SECRET / VK_CLIENT_ID настраиваются отдельно; рабочие секреты и production-БД для превью не нужны.
